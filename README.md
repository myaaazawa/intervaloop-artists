## 日本語

クロッキーやジェスチャードローイングなど、絵の練習のためのタイマー付きアプリです。
参考画像を読み込んでおくと、決めた時間ごとに画像が切り替わります。
ブラウザで使え、インストールや登録は必要ありません。

**アプリを開く：** https://myaaazawa.github.io/intervaloop-artists/

### 主な機能

- **練習メニュー**：「ポーズ時間 × 回数」を段階ごとに組み合わせられる（例：30秒×10 → 1分×5 → 2分×3）
- チェンジ（ポーズとポーズのあいだの時間）、開始前のカウントダウン、合計時間の表示
- ポーズごとに、参考画像が1枚ずつ切り替わる
- **画像の追加**：フォルダー・ファイルの選択、ドラッグ＆ドロップ、貼り付け、URL（最大500枚）
- 画像を「セット」に分けて管理、★をつけた画像だけで練習、使わない画像の指定、シャッフル
- **表示の道具**：左右反転、白黒、明暗強調、3階調、シルエット、グリッド、拡大・縮小
- 練習のあとに、描いた画像を並べて振り返り
- メニューの保存（9件まで）、データの書き出し・読み込み（バックアップ）
- 時間送り・巻き戻し、先頭へ、スキップ、丸いバーの操作のロック
- 8種類の音と音量、残り数秒の合図、色・背景（自動／ライト／ダーク）、日本語・英語、全画面表示
- パソコン・スマートフォン・タブレットに対応

### 使い方

1. 練習に使う画像を追加します（画面にドラッグ＆ドロップするのがいちばん簡単です）。
2. 「練習メニュー」で、ポーズ時間と回数を決めます。
3. 「開始」を押すと、カウントダウンのあとに練習が始まり、ポーズごとに画像が切り替わります。

A drawing-practice app with a built-in timer, made for croquis, gesture drawing and similar exercises.
Load your reference images, and they change automatically after each pose.
It runs in your browser. No installation or sign-up needed.

**Open the app:** https://myaaazawa.github.io/intervaloop-artists/

### Features

- **Practice menu**: combine "pose time × count" in stages (e.g. 30s ×10 → 1m ×5 → 2m ×3)
- Change time (the break between poses), countdown before start, and total time display
- A new reference image for each pose
- **Add images**: choose a folder or files, drag and drop, paste, or enter a URL (up to 500 images)
- Organize images into sets, practice with starred images only, mark images to skip, and shuffle
- **View tools**: flip, black and white, contrast boost, 3 tones, silhouette, grid, zoom
- Review the images you drew after each session
- Save up to 9 menus, and export / import all your data as a backup
- Back / forward, restart, skip, and a lock for the ring
- 8 sound types and volume, a soft beep in the last few seconds, custom colors, background (Auto / Light / Dark), Japanese and English, full screen
- Works on computers, smartphones and tablets

### How to use

1. Add the images you want to practice with (dragging them onto the page is the easiest way).
2. Set the pose times and counts in "Practice menu".
3. Press "Start". After the countdown, practice begins and the image changes with each pose.
